## Platform

web

## Users

依既有需求規格書推定，主要使用者為台灣的 LINE 會員與玩具／公仔／戰鬥陀螺購買者；訪客可瀏覽、搜尋商品與加入購物車。管理員為店家營運人員，共同管理商品、庫存、訂單、會員、積分、優惠券與通知。

## Product Purpose

「潮吉好頑」提供手機優先的一頁式玩具選物購物流程，讓顧客瀏覽現貨與預購商品、加入購物車、以 LINE 登入建立訂單、回報匯款並查看訂單／積分／優惠券。系統同時支援店家人工確認付款、庫存異動、會員 LINE 通知與管理員 Telegram 通知。

成功條件是顧客能清楚完成選品與下單，管理員能可靠確認款項、扣除庫存、處理到貨／尾款／運費並留下不可覆寫的紀錄。

## Positioning

依既有規格推定，產品定位是以 LINE 會員與人工客服流程為核心的玩具選物店，而不是串接完整自動金流與物流的平台。預購訂金、匯款確認、客服通知實際運費與管理員核銷是其主要營運機制。

## Operating Context

- 前台部署於 Cloudflare Workers，資料與 Auth、Storage、Cron 使用 Supabase。
- 商品類型包含玩具、公仔、戰鬥陀螺；現貨與預購規則不同，每個規格有獨立價格與庫存。
- 店取地址為台南市中西區民生路二段 93 號，週二公休，14:00–20:00。
- 到店取貨免運；現貨賣貨便依「加入購物車 → 選賣貨便 → 建立本站待確認訂單 → 前往賣貨便 → 管理員人工核對」流程，運費由 7-11 向客戶收取。預購賣貨便先在本站匯款付訂，到貨後由客服通知並開立賣貨便；宅配運費於到貨後由客服通知，尾款與運費確認後才安排寄送。
- LINE 官方帳號用於會員通知與客服；首頁客服連結與結帳測試好友連結是不同用途，須維持各自設定。

## Capabilities and Constraints

- LINE Login 為會員登入入口；首次登入需補填姓名與手機，生日、地址選填。
- 結帳前必須完成 LINE 官方帳號好友／可推播檢查；未通過時可瀏覽但不可建立訂單。
- 支援現貨、預購與混購分單；本站到店取貨、宅配與預購賣貨便訂金一律匯款／轉帳，現貨賣貨便使用外部付款，不新增信用卡、TWQR 或全支付流程。
- 訪客購物車先保存在瀏覽器；LINE 登入後會與會員雲端購物車合併並同步，支援跨裝置續購。
- 預購訂金固定 50%；匯款訂單有付款期限與管理員確認流程；庫存以保留、確認扣除與異動帳本保護。
- 管理員可管理商品、規格、主圖、限購數量、庫存、訂單、會員、點數、優惠券與收款帳戶；管理端事件透過 Telegram Bot 通知。
- 賣貨便與宅配訂單可於到貨後記錄實際運費、尾款匯款末五碼與確認狀態；未確認前不可完成寄送訂單。
- 會員點數採帳本制，訂單完成入點、退款／取消依規則沖回；優惠券可限制商品、會員、期限、次數與點數併用。
- 商品目前以主圖為主；多圖圖集與規格圖片是後續待完成項目。
- 本期不包含本站串接賣貨便訂單狀態、線上電子支付金流、CSV／Excel 報表匯出。

## Product Principles

1. 先讓顧客清楚知道商品狀態、價格、訂金與取貨規則，再引導下單。
2. 付款、庫存、點數與訂單狀態都要以資料庫交易與不可覆寫紀錄保護。
3. LINE 是會員識別、通知與客服的主要營運通道，但未登入者仍可瀏覽商品。
4. 人工客服處理的運費、尾款與個案退款必須有明確欄位與管理員紀錄。
5. 手機操作優先，表單、彈窗、提示與管理後台在小螢幕上仍應可讀、可操作。

## Accessibility & Inclusion

- 以手機優先設計，支援桌機、平板與手機版面。
- 表單欄位需有清楚標籤、錯誤訊息與成功回饋；彈窗關閉操作在內容捲動時仍保持可見。
- 輸入框在手機瀏覽器上使用不會觸發非預期頁面縮放的字體尺寸。
- 重要訂單、付款與庫存結果不得只以顏色表示，需同時提供文字說明。
