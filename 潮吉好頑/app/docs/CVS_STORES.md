# 7-11 取件門市清單

改門市清單的讀取、後台抓取／上傳／發佈，或更新內建門市檔時讀這份。從 `AGENTS.md` 移出。

7-11 取件門市：結帳讀 `/cvs-stores/index.json` 與 `/cvs-stores/<slug>.json`，由 Worker（`src/cvs-stores-serve.ts`，`wrangler.jsonc` 的 `run_worker_first` 含 `/cvs-stores/*`）先讀後台發佈的 R2 版本（`PRODUCT_IMAGES` bucket 的 `cvs-stores/` 前綴，`current.json` 指標最後才寫入），沒有發佈過就回到 repo 內建的 `app/public/cvs-stores/*.json`（靜態檔缺的縣市回 JSON 404，不回 SPA）。更新流程：後台「7-11 門市」分頁按「從 7-11 官方網站抓取」（Worker `src/cvs-stores-fetch.ts` 代查官方電子地圖，每次一個縣市的 `EMAP_TOWNS_PER_REQUEST` 個鄉鎮（3 個，維持在 Workers Free CPU 額度內），用戶端只送白名單縣市與 offset；瀏覽器 `public/cvs-stores-fetch.js` 遇到網路中斷／5xx／429 自動重試，收齊後以 `public/cvs-road-name.js`（逐行移植自 Python 的路名規則，兩邊要一起改）產生同格式 CSV，任何縣市／鄉鎮失敗就不產生結果，可只重抓失敗的縣市；可下載 CSV），或執行備案 `app/scripts/fetch_711_stores.py`（同樣抓取並抽出路名，輸出 6 欄 CSV 到 `scripts/711-data/`，筆數明顯變少或抓取失敗不寫入）→ 後台「7-11 門市」分頁上傳 CSV（瀏覽器端用 `public/cvs-stores-data.js` 解析並比對差異，缺縣市／店號重複／總數少超過 5% 不可發佈；逐縣市暫存到 R2 再發佈，伺服器端 `src/cvs-stores-admin.ts` 重新驗證、只保留最近 5 版，可回復舊版或回到內建檔案）。內建檔仍可用 `node scripts/build-cvs-stores.mjs scripts/711-data/711_stores_sorted.csv` 產生（會刪除重建 `public/cvs-stores/`，測試不可執行它）。縣市白名單在 `public/cvs-stores-data.js` 與 `src/cvs-stores.ts` 各一份（Worker 不能 import `public/`），`tests/worker/cvs-stores.test.mjs` 比對一致。Python 測試：`python -m unittest discover tests/scripts`（不在 `npm test` 內）。
