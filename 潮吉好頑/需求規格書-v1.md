## 1. 範圍與原則

### 本期包含

- 前台商品瀏覽、搜尋、分類、規格選擇、購物車與到店取貨下單。
- LINE Login 會員、會員資料、訂單紀錄、積分／優惠券紀錄。
- 現貨與預購、訂金匯款末五碼；預購訂單成立後 2 小時、現貨訂單 24 小時內完成匯款。
- 管理端的商品、規格、庫存、訂單、會員、積分、優惠券、收款帳戶與通知管理。
- 購物車內選擇賣貨便後，建立本站待確認訂單，再導向賣貨便外部結帳。
- LINE 官方帳號的「確認訂金」、「可取貨」及「生日券」通知。

### 本期不包含

- 賣貨便平台的 API 付款或訂單狀態自動串接（本站只建立待確認紀錄並由管理員人工核對）。
- 宅配／超商寄送的本站訂單流程。
- 線上信用卡／電子支付金流。
- 報表或 CSV／Excel 匯出。

### 設計原則

- 行動裝置優先；商品格手機 2 欄、平板 4 欄、桌機 4 欄。
- 品牌色為鵝黃色、白、黑；產品操作以清晰、明亮的玩具選物店調性為主。
- 所有金額以新台幣（NT$）整數計算。
- 庫存、積分、訂單狀態均需有不可覆寫的異動紀錄。

| 管理員（3 位） | 共同完整管理權限；可管理商品、訂單、會員、積分、優惠券、收款帳戶與系統設定。 |

## 3. 前台資訊架構

1. **首頁／商品目錄**：品牌、公告、分類、搜尋、現貨／預購篩選、商品列表、購物車入口、LINE 登入入口。
2. **商品詳情彈窗／頁面**：主圖、系列、規格、價格、庫存／預購到貨區間、訂金說明、數量與加入購物車；賣貨便從購物車選擇。
3. **購物車**：明細、數量調整、庫存或預購狀態、優惠券、積分折抵、訂單金額試算。
4. **結帳**：LINE 登入、姓名與手機、到店取貨資訊、混購取貨方式、付款／訂金、收款帳戶選擇、匯款末五碼、條款同意、建立訂單。
5. **會員中心**：基本資料、訂單列表／明細、積分帳本、可用優惠券。

## 4. 商品與庫存

### 商品欄位

商品名稱、系列／分類、SKU、描述、封面與圖集、上下架狀態、限購數量、賣貨便連結、成本、安全庫存、售價策略。

### 規格欄位

每個商品可有系列、款式、顏色、尺寸、隨機款等多規格。每個規格各自設定 SKU、售價、成本、可售庫存、安全庫存、預購設定與賣貨便連結。

### 商品類型

| 類型 | 規則 |
| --- | --- |
| 現貨 | 依規格庫存銷售。後台可設定全額付款或部分訂金。 |
| 預購 | 每個規格可設定預計到貨區間；固定收總額 50% 訂金。 |

### 庫存保留與扣庫存

1. 建立訂單後立即建立 `inventory_reservations`，可售數量扣除保留數量，但正式庫存帳本尚不扣除。
2. 預購訂單於 2 小時內、現貨訂單於 24 小時內尚未經管理員確認付款／訂金，系統自動取消並釋放保留量。
3. 管理員確認付款／訂金後，建立正式 `inventory_movements` 扣庫存紀錄。
4. 取消、退款或未取貨時，依管理員處理結果建立相應庫存異動；不可直接覆寫既有紀錄。
5. 規格可售量達 3 件或以下時，通知三位管理員。

## 5. 下單與付款流程

### 本站到店取貨訂單

1. 會員選擇商品規格與數量後加入購物車。
2. 結帳前須 LINE 登入。姓名、手機為必填；生日、地址可填寫但不強制。
3. 顧客選擇本組商品的取貨方式（到店取貨／賣貨便／宅配）；購物車同時含現貨與預購時，前台先分組，顧客須分別完成兩筆訂單。
4. 系統套用有效優惠券與積分折抵，依後台設定檢查是否可併用。
5. 顧客選擇收款帳戶。預購收 50% 訂金；現貨依商品設定收全額或部分訂金。
6. 顧客選擇收款帳戶並填寫匯款帳號末五碼，送出訂單；本站到店取貨訂單一律匯款／轉帳，不提供到店現金支付。
7. 系統保留庫存並依商品類型啟動付款期限（預購 2 小時、現貨 24 小時）；通知管理員檢查付款。
8. 管理員確認款項後，訂單轉為已確認／備貨中，正式扣庫存。
9. 商品可取貨後，系統以 LINE 通知顧客、以 Telegram 通知管理員。
10. 管理員手動核銷完成訂單，系統依設定發送積分。

### 賣貨便

- 商品先加入購物車，會員在購物車選擇「賣貨便」。
- 系統先建立本站「賣貨便待確認」訂單，再導向該商品／規格設定的賣貨便連結。
- 管理員與賣貨便外部訂單人工核對，確認後更新本站訂單並扣除庫存；賣貨便運費由 7-11 向客戶收取，不加入本站訂單。
- 現貨賣貨便：系統先建立本站「賣貨便待確認」訂單，再導向該商品／規格設定的賣貨便連結；管理員核對後更新本站狀態並扣庫存。
- 預購賣貨便：不需預先設定外部連結，先在本站匯款支付 50% 訂金；到貨後由客服通知並開立賣貨便，尾款由 7-11 取貨時收取。

### 訂單狀態

`待付款` → `待確認訂金` → `已確認／備貨中` → `部分可取貨` → `可取貨` → `已完成`

可由管理員轉為：`已取消`、`退款處理中`、`已退款`。取消與退款採個案人工處理。

### 店取資訊

地址：台南市中西區民生路二段 93 號  
營業／取貨時間：週二公休，14:00–20:00  
到店取貨訂單一律匯款／轉帳；到店取貨免運費。

## 6. 會員、積分與優惠券

### 會員

- LINE Login 為會員登入唯一入口。
- 首次登入必填姓名、手機；生日、地址為選填。
- LINE `userId` 為會員唯一識別，不以手機作主鍵。

### 積分

| 項目 | 初始設定 | 後台可調整 |
| --- | --- | --- |
| 消費累積 | 每 NT$100 得 1 點 | 是 |
| 折抵價值 | 1 點折 NT$1 | 是 |
| 最低使用 | 1 點 | 是 |
| 單筆折抵上限 | 由管理員設定固定金額或訂單百分比 | 是 |
| 有效期限 | 永不到期 | 是 |
| 入帳時點 | 管理員核銷為已完成 | 是 |

積分採帳本模式：消費入點、使用扣點、訂單取消沖回、退款扣回、人工調整均新增一筆交易，不可改寫歷史餘額。

### 優惠券

- 固定金額折扣。
- 後台可設定代碼、面額、有效期間、最低消費、適用商品／會員、總使用次數、每會員使用次數，以及是否可與積分併用。
- 生日券由後台設定面額、發送時間、有效天數、最低消費與併用規則；由排程於生日條件符合時發送。

## 7. 售後與通知

### 正式公開文案

產品真實資料、退換貨及代購規則，以目前正式首頁 `public/index.html` 的「購物須知」文案為準；本文件不另行改寫或加入其他承諾。首頁目前公開內容為：

- 付款完成視同同意所有代購資訊與交易規則；送出訂單前，請確認商品、款式、取貨方式與付款內容。
- 預購：海外海運與集運，依實際進度到貨；出貨地區、集運批次、海關與天候都可能影響時間。
- 付款：本站到店取貨與宅配訂單一律匯款／轉帳；預購商品訂金為總價 50%，現貨依商品規格設定收全額或部分訂金。預購成立後 2 小時內需完成付訂，現貨匯款期限為 24 小時。
- 退換貨：付款完成視同同意交易規則；不接受任何原因退換貨，請下單前確認。
- 完整規則：新品發售／商品預訂後，需經國外出貨、海運與集運安排，實際到貨時間會依出貨地區、集運批次、海關查驗、颱風等天候因素變動，無法保證於固定天數內到貨；如有最新進度，會再由客服通知。另不保商品價格漲跌、官方產品瑕疵、國際物流運送盒損、海關查驗拆檢，以及寄送貨物遺失／毀損；到貨通知後需於 7 日內付完尾款，逾期可能視同棄單，訂金不退還且商品不保留。

- 未取貨商品保留 3 個月；逾期處理由管理員個案處理。
- 客服管道為正式 LINE 官方帳號 `@078isxfl`。
- 管理員確認訂金、可取貨等訂單事件，以 LINE 通知顧客、以 Telegram 通知管理員；會員回報匯款與低庫存只通知 Telegram 管理員，生日券只通知 LINE 會員。

## 10. 安全與驗收

- Supabase Row Level Security：會員僅能存取自己的資料；後台 API 必須驗證管理員身分。
- LINE Channel Secret、Supabase Service Role、通知 Token 只保存於 Cloudflare Secrets，不進前端。
- 收款帳號僅在待付款結帳／訂單明細的授權情境顯示；管理端操作寫入稽核紀錄。
- 建立訂單、扣庫存、使用點數、核銷完成必須在資料庫交易內執行，避免超賣與重複扣點。
- 驗收時至少涵蓋：現貨下單、預購 50% 訂金、混購分單、現貨／預購賣貨便差異、付款逾期取消、取消／退款、積分入扣、優惠券併用、低庫存、LINE 會員通知、Telegram 管理員通知與商品外連。
